# Phase 1.1 — Rename to Ariadne.NET Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every `ArchGov` name in code, packages, CLI and docs becomes Ariadne.NET, with behaviour unchanged.

**Architecture:** A scripted rename. First `git mv` the project folders, project files and solution; then run one ordered text replacement, most specific name first. The compiler, the existing 258 tests and a `git grep` gate prove nothing was missed. Four tasks follow the impact analysis's execution groups; each ends green and committed.

**Tech Stack:** .NET 10, `dotnet` CLI, slnx, ZInject 0.10.5 source generator, Docusaurus (docs-site), git, GNU sed.

**Spec:** `docs/superpowers/specs/2026-10-31-phase-1.1-rename-design.md`; impact analysis: `docs/superpowers/specs/2026-10-31-phase-1.1-rename-impact-analysis.md` (read both — the analysis's Affected Files table and Risk Register are the authoritative file list).

## Global Constraints

- Namespace = assembly = package ID = `Ariadne.NET.*`.
- Project map: `ArchGov.Core` → `Ariadne.NET`, `ArchGov.Host.Mcp` → `Ariadne.NET.Mcp`, `ArchGov.Host.Cli` → `Ariadne.NET.Cli`, `ArchGov.Host.Api` → `Ariadne.NET.Mcp.Http`, `ArchGov.Core.Tests` → `Ariadne.NET.Tests`, `ArchGov.Host.Mcp.Tests` → `Ariadne.NET.Mcp.Tests`, `ArchGov.Host.Cli.Tests` → `Ariadne.NET.Cli.Tests`, `src/ArchGov.slnx` → `src/Ariadne.NET.slnx`. Folders match project names.
- ZInject methods: `AddArchGovCoreServices` → `AddAriadneNETServices`, `AddArchGovHostMcpServices` → `AddAriadneNETMcpServices`.
- Strings: `archgov://` → `ariadne://`; `'archgov sync'` → `'ariadne sync'`; MCP server key `"archgov"` → `"ariadne"`; `ARCHGOV-` → `ARIADNE-`; author `archgov-team` → `ariadne`; temp prefixes `archgov-` → `ariadne-`.
- Never touch `docs/plans/`, `docs/planning/`, `docs/superpowers/`, the `.architecture/` folder name, or the repo URLs / `baseUrl` / `projectName` in `docs-site/docusaurus.config.js` (Phase 1.4).
- Baseline: build 0 errors, 27 warnings; tests 224 + 25 + 9 = 258 passing. No task may add a warning or lose a test.
- Work in this worktree; push with `git push -u origin HEAD:fix/mcp-composite-template` (the branch is checked out in the main worktree).
- Commit messages: conventional commits, no nested parentheses in bodies, no Claude signature or session link.

## Review Focus

1. Built-in packs are still found by name after the embedded-resource prefix changes — `BuiltinPackRegistryTests` must still list and load all 10 packs (Task 1 Step 6 checks the count explicitly).
2. An MCP client reading `ariadne://packs/clean-architecture` gets the YAML — `PackResourcesTests` asserts the new URI template (Task 2 Step 2).
3. A user who hits a missing-import error is told to run `ariadne sync`, not `archgov sync` — Task 2 Step 3 adds an assertion on that message.
4. No half-renamed identifiers such as `Ariadne.NET.Host.*`, `Ariadne.NET.Core` or `Ariadne.NET.Api` — grep gate in Task 1 Step 6.
5. Docs and Mermaid diagrams still render with the new labels — Task 3 Step 4 builds the docs site when Node is available.

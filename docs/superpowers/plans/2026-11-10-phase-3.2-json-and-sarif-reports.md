# Phase 3.2 — JSON and SARIF reports Implementation Plan

> Execution method: none now. This plan is built later, by an unattended run or by `start-next-phase`. Phase 3.1 must be merged first.

**Design:** `docs/superpowers/specs/2026-11-10-phase-3.2-json-and-sarif-reports-design.md`
**Builds on:** Phase 3.1 — `ArchitectureViolation.Pack`, `TextReportWriter.Write(TextWriter, ArchitectureReport, string)`, `IPackSetValidator.ValidateAsync(string, CancellationToken)`, `ArchitectureCheck.Run(string?)`.
**Goal:** JSON and SARIF 2.1.0 reports from the CLI and the testing package, validated against the published SARIF schema.
**Approved public API:** `JsonReportWriter`, `SarifReportWriter`, `ReportContext`, `ReportRoot`, `ReportFormat`, `ArchitectureCheck.WriteReport` and the `AssertValid` report overload, and the `--format` and `--output` options of `ariadne validate`. Approved by the owner with the milestone 3 design on 2026-11-10 and confirmed for the unattended run; none of it is a breaking change.
**Conventions:** conventional commits, no nested parentheses in bodies, no `Co-Authored-By` trailer or session link, footer lines under 100 characters. `TreatWarningsAsErrors` is on; one type per file. One build or test at a time.

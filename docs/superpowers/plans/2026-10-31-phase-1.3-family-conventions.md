# Phase 1.3 Family Conventions Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Ariadne.NET returns `Result<T, AriadneError>` for expected failures in the pack pipeline and sync, builds with zero warnings under `TreatWarningsAsErrors`, and uses ZeroAlloc.Inject, Validation, Telemetry and Resilience.

**Architecture:** `AriadneError` (a record struct plus a code enum) and the Result-returning pack contracts live in `Ariadne.NET.Abstractions`, which gains ZeroAlloc.Results and ZeroAlloc.Validation. The engine converts every expected failure in `RuleLoader/` and `Sync/` to a Result. It wraps git in an internal Resilience proxy, and wraps the public operations in internal Telemetry proxies. The CLI and MCP map errors to exit code 2 and to tool errors.

**Tech Stack:** .NET 10, ZeroAlloc.Results 1.4.5, ZeroAlloc.Inject / Analyzers / Validation / Telemetry / Resilience (latest), YamlDotNet 16.3, xUnit + FluentAssertions, ModelContextProtocol 1.1.0, System.CommandLine 3.0 preview.

**Spec:** `docs/superpowers/specs/2026-10-31-phase-1.3-family-conventions-design.md`. The impact analysis is `docs/superpowers/specs/2026-10-31-phase-1.3-family-conventions-impact-analysis.md` (affected files, risks, group order). Read both before starting.

## Global Constraints

- `AriadneError` is `public readonly record struct AriadneError(AriadneErrorCode Code, string Message, string? Detail = null)`, and `AriadneErrorCode` is `{ NotFound = 1, Invalid = 2, Unavailable = 3 }`. The value 0 stays undefined.
- Expected failures return Results and never throw. `ArgumentNullException` guards and the "embedded resource missing" packaging bug stay as throws. No `catch (Exception)` may turn bugs into `AriadneError`s.
- Change signatures in place. Add no `Try*` twins.
- No `NoWarn` or `#pragma` to reach zero warnings, apart from a provably wrong analyzer finding. Such a suppression is local, carries a justification comment, and is reported in the task's review notes.
- `Ariadne.NET.Abstractions` references only `ZeroAlloc.Results` and `ZeroAlloc.Validation`, plus `ZeroAlloc.Validation.Generator` with `PrivateAssets="all"`. It stays `IsAotCompatible`, and this must pass: `dotnet publish tests/Ariadne.NET.AotSmoke -c Release -r linux-x64 -p:PublishAot=true -warnaserror`.
- No Telemetry or Resilience types in Abstractions. Instrumented interfaces and `IGitClient` are `internal` to the engine.
- CLI: every `AriadneError` prints `Error: {Message}` to stderr, then `{Detail}` on the next line when present, and exits with `ExitCodes.Error` (2). Exit code 1 stays "violations found".
- Telemetry ActivitySource and Meter name: `Ariadne.NET`, exposed as `public const string SourceName` on `Ariadne.NET.Telemetry.AriadneTelemetry`. Tags carry pack and import names, never file contents.
- Resilience on `IGitClient`: `[Timeout(Ms = 60_000)]`, `[Retry(MaxAttempts = 3, BackoffMs = 500)]`. A caller's cancellation propagates as `OperationCanceledException`.
- No validation rule may reject `clean-architecture`, `hexagonal-architecture`, `cqrs`, or any YAML fixture under `tests/`.
- Commits: conventional (`type(scope): subject`). Leave out the `Co-Authored-By` trailer and the session link. Avoid nested parentheses in commit bodies, because release-please drops such a commit.
- Work in the worktree, and push with `git push -u origin HEAD:fix/mcp-composite-template`.
- Build: `dotnet build src/Ariadne.NET.slnx`. Test: `dotnet test src/Ariadne.NET.slnx`. The baseline is 263 passing tests (227 + 26 Mcp + 10 Cli).

## Review Focus

1. **An empty `.architecture/rules.yaml` or imports file.** YamlDotNet returns `null` for an empty document, and the loaders must return Invalid ("file is empty"), not throw a `NullReferenceException` later. The tests are in Tasks 6 and 8.
2. **Valid YAML of the wrong shape**, such as a sequence at the root or `layers: "text"`. YamlDotNet throws a `YamlException` subtype, and the result must be Invalid with the line number, not a crash. The test is in Task 6.
3. **An unreadable rules file**, where the path is a directory or access is denied. The result must be Unavailable with the OS message in Detail, not an unhandled `IOException` or `UnauthorizedAccessException`. The test is in Task 6.
4. **`git` not installed.** `Process.Start` throws `Win32Exception`, and sync must report Unavailable for that import ("git could not be started"), not crash the CLI. The test is in Task 9.
5. **A pack name in a different case**, such as `builtin://Clean-Architecture`. The registry is case-insensitive today, and that must survive the Result conversion and the Telemetry wrapping. The test is in Task 5.

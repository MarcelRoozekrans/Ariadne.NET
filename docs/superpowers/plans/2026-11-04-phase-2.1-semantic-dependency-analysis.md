# Phase 2.1 Semantic Dependency Analysis Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** CLI `validate` and MCP `validate_source` check a `.sln`, `.slnx`, `.slnf` or `.csproj` against the v1 layer and role rules on the semantic type graph of its compilations, `SourceValidator` is deleted, and `Ariadne.NET.Workspaces` ships as the third package.

**Architecture:** The core `Ariadne.NET` gains an `Analysis` namespace: a bound syntax walk turns each `Compilation` into type edges with locations, v1 layer and role rules run on those edges, and `IArchitectureValidator` merges the results per project and target framework into an `ArchitectureReport`. The new `Ariadne.NET.Workspaces` package resolves a path, loads it through MSBuildWorkspace, fails on an incomplete load, and exposes `ISolutionValidator`, which the CLI and MCP server both call.

**Tech Stack:** C# / .NET 10, Roslyn 5.9.0 (`Microsoft.CodeAnalysis.CSharp`, `Microsoft.CodeAnalysis.Workspaces.MSBuild`), possibly `Microsoft.Build.Locator`, ZeroAlloc.Results, ZeroAlloc.Inject, ZeroAlloc.TestHelpers, xunit 2.9.3, FluentAssertions 8.

**Spec:** `docs/superpowers/specs/2026-11-04-phase-2.1-semantic-dependency-analysis-design.md`. Binding input: `docs/superpowers/specs/2026-11-04-milestone-2-design.md`, sections "Decisions" and "Calls made". Read both before starting.

## Global Constraints

- Shared VM: run builds and tests one at a time, never in parallel. Never run a Native AOT publish locally; the AotSmoke publish runs in CI only.
- `TreatWarningsAsErrors` is on for the whole repo, with Meziantou, Roslynator, ErrorProne.NET, Hyperlinq and ZeroAlloc analyzers. Fix warnings, never suppress them.
- Roslyn packages stay at 5.9.0, the version `src/Ariadne.NET/Ariadne.NET.csproj` already uses.
- `Ariadne.NET` must not reference MSBuild, `Microsoft.CodeAnalysis.Workspaces.MSBuild` or `Microsoft.Build.Locator`. Only `Ariadne.NET.Workspaces` does.
- No `Microsoft.Build.*` assembly may land in the CLI's or MCP server's output folder.
- `Ariadne.NET.Abstractions` does not change in this phase; the AotSmoke test must stay green.
- Expected failures return `Result<T, AriadneError>`; argument nulls throw `ArgumentNullException`, as elsewhere in the engine.
- Commits: conventional commits; no `Co-Authored-By` trailer, no session link; no nested parentheses in commit bodies. Implementation runs on the branch `feat/phase-2.1-semantic-analysis`, in its own worktree, created from `ariadne/main` after the design PR #23 has merged. Push with `git push ariadne HEAD:feat/phase-2.1-semantic-analysis`, never to `origin`.
- Breaking commits carry `!` in the header and a `BREAKING CHANGE:` footer: Tasks 11, 12 and 13.
- Exit codes keep their meaning: 0 clean, 1 violations, 2 error.

## Review Focus

1. **Several test assemblies restoring the same fixture at once.** `dotnet test` on the solution runs the Workspaces, CLI and MCP test assemblies in parallel processes. Expected: the fixture restore is serialised by a cross-process lock and never corrupts `obj/`. The test is in Task 9.
2. **A path with spaces or a relative path from another working directory.** Expected: it resolves exactly like an absolute path. Tests in Task 9.
3. **A solution whose projects all fail to load, or that has zero C# projects.** Expected: an `Invalid` error, never a valid report with 0 types. Tests in Task 10.
4. **A violation whose location is in a file under `obj/`,** such as SDK-generated global usings. Expected: none is ever reported. Test in Task 10.
5. **A type referencing a forbidden type through an alias or a fully qualified name, with no `using`.** Expected: it is reported, which is the false negative of issue #1 in another shape. Tests in Task 5.

### Task 5: Type graph builder

**Model:** opus. The bound syntax walk is the core of the milestone, and binding edge cases decide every later verdict.

**Files:**

    - `SourceTypes` holds every named type, nested types included, that has at least one declaration in a non-generated tree and no `[GeneratedCode]`.
    - It is ordered by the first declaration's file path, line and column.
  - `internal static class TypeGraphBuilder` with `static TypeGraph Build(Compilation compilation, IReadOnlySet<SyntaxTree> generatedTrees, CancellationToken cancellationToken)`.
  - Symbols are compared with `SymbolEqualityComparer.Default`.

- [ ] **Step 1: Write the failing tests.** Add a test helper `Edges(string source)` that returns `(string Source, string Target)` pairs, using the types' `ToDisplayString()`. Each test asserts that the pair `Shop.Domain.Order → Shop.Infra.Store` is present, unless the test says otherwise:

  - **Bookkeeping:** `NestedType_IsSourceOfItsOwnEdges`; `Location_IsLineAndColumnOfTheName`, which asserts the exact 1-based line and column; `DuplicateReferences_OneEdgePerLocation`; and `SourceTypes_ExcludesGeneratedTypes`.
- [ ] **Step 2:** Run with `--filter TypeGraphBuilderTests`. Expected: compile failure.
- [ ] **Step 3: Implement** the walker as a `CSharpSyntaxWalker` over each non-generated tree, with one `SemanticModel` per tree.
  - **What it binds:** `IdentifierNameSyntax`, `GenericNameSyntax` and `ImplicitObjectCreationExpressionSyntax`. Skip an identifier where `IsVar` is true. Resolve an `IAliasSymbol` to its target.
  - **The source:** the innermost enclosing `BaseTypeDeclarationSyntax` or `DelegateDeclarationSyntax` symbol. Top-level statements resolve to the compiler's `Program` type through the semantic model's enclosing symbol.
  - **Target normalisation:**
    - a member becomes its `ContainingType`;
    - a named type becomes its `OriginalDefinition`;
    - an array or pointer becomes its element type;
    - a reduced extension method becomes its `ReducedFrom` containing type;
    - `ITypeParameterSymbol`, `IDynamicTypeSymbol`, error types, namespaces and self-edges are dropped.
  - **De-duplication:** on source, target and location. Order edges by location.

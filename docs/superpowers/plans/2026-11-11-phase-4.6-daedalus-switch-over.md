# Phase 4.6 Daedalus Switch-over Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Daedalus.NET checks its architecture with an Ariadne pack through one `Ariadne.NET.Testing` test, with its ArchUnitNET tests and package removed, and Ariadne's migration guide shows the pack Daedalus ships.

**Architecture:** Tasks 1 to 4 run in a session on the Daedalus.NET repository, on one branch and one PR: the pack and test are added next to the ArchUnitNET tests, every rule group is checked red, then ArchUnitNET is deleted. Task 5 runs in Ariadne.NET after that PR has merged and updates the guide's worked example. Phase 4.6 completes in Ariadne through `complete-phase`.

**Tech Stack:** .NET 10, xUnit, `Ariadne.NET.Testing` from nuget.org, Daedalus's central package management, Docusaurus.

**Spec:** `docs/superpowers/specs/2026-11-11-phase-4.6-daedalus-switch-over-design.md`

## Global Constraints

- Not built by an unattended run of Ariadne.NET. Tasks 1 to 4 run in Daedalus.NET; Task 5 in Ariadne.NET.
- `Ariadne.NET.Testing` comes from nuget.org at the latest release, which must contain Phase 4.2's selector traits. Never a local feed or a project reference. If the release lacks them, stop and ask the owner to merge the release-please PR.
- Daedalus files: pack `.architecture/rules.yaml` at the repository root; test `tests/Daedalus.Tests.Unit/Architecture/AriadneArchitectureTests.cs`, class `AriadneArchitectureTests`, one fact `Solution_follows_the_architecture_pack`, calling `ArchitectureCheck.AssertValid(<path of Daedalus.sln>)`.
- Delete exactly `tests/Daedalus.Tests.Unit/Architecture/CleanArchitectureTests.cs` and `NoEntityFrameworkTests.cs`, and `TngTech.ArchUnitNET.xUnit` everywhere. Keep `NuGetPackageRootPathTests.cs` and `tests/Daedalus.Tests.Integration/Architecture/CleanArchitectureTests.cs`.
- The `Directory.Packages.props` part of the package-absence facts is dropped on purpose, and the PR body says so.
- Daedalus conventions: conventional commits, PR required, squash merge; the owner merges. No `Co-Authored-By` trailer, no session link, no nested parentheses in commit bodies.
- Never commit a red-check mutation.
- Shared VM: one build or test at a time.

## Review Focus

- **A rule that passes vacuously.** Every rule group must go red under its mutation, with the expected id in the message. Pinned in Task 3.
- **A Daedalus fact added after `1dd470b7` left untranslated.** Pinned in Task 1 Step 3 and in Task 5's map check.
- **The test finding the wrong solution or no pack.** `Solution_follows_the_architecture_pack` must fail with a clear message, not pass, when `.architecture/rules.yaml` is missing. Pinned in Task 2 Step 4.
- **An Ariadne-versus-ArchUnitNET difference on Daedalus code.** Each one is a listed divergence with a pack adjustment, or a stop. Pinned in Task 2 Step 5.
- **A stray ArchUnitNET reference after the delete.** Pinned in Task 4 Step 2.

### Task 1: Preconditions and the pack

**Files (Daedalus.NET):**
- Create: `.architecture/rules.yaml`

**Interfaces:**
- Consumes: the `daedalus` pack and test map in Ariadne's `docs-site/docs/migrating-from-archunitnet.md` on `main`.
- Produces: `.architecture/rules.yaml`, and a list of facts added, changed or removed since `1dd470b7`, used by Task 5.

- [ ] **Step 1: Run the guard check, in Ariadne.NET** — `dotnet test tests/Ariadne.NET.Tests --filter "FullyQualifiedName~MigrationGuideSnippetTests" -- RunConfiguration.TreatNoTestsAsError=true`. Expected: PASS. If it fails, stop and report: Phase 4.5 drifted from what this plan uses.
- [ ] **Step 2: Check the release** — find the latest `Ariadne.NET.Testing` on nuget.org and confirm its release notes or the Ariadne `CHANGELOG.md` at that tag list the Phase 4.2 selector traits and the Phase 4.3 slices. If not, stop and ask the owner.
- [ ] **Step 3: Diff Daedalus's architecture tests** — branch from Daedalus `main`; `git diff 1dd470b7 HEAD -- tests/Daedalus.Tests.Unit/Architecture tests/Daedalus.Tests.Integration/Architecture`. List each fact added, changed or removed.
- [ ] **Step 4: Write the pack** — copy the guide's `daedalus` pack to `.architecture/rules.yaml`, then apply Step 3's list with the guide's construct map. A fact that needs a rule kind Ariadne lacks stays a C# fact: report it to the owner and file an Ariadne issue with `gh issue create` in `MarcelRoozekrans/Ariadne.NET`.
- [ ] **Step 5: Commit** — `test: add the Ariadne architecture pack`.

### Task 2: The Ariadne test, side by side

**Files (Daedalus.NET):**
- Create: `tests/Daedalus.Tests.Unit/Architecture/AriadneArchitectureTests.cs`
- Modify: `Directory.Packages.props`, `tests/Daedalus.Tests.Unit/Daedalus.Tests.Unit.csproj`

**Interfaces:**
- Consumes: `.architecture/rules.yaml` from Task 1; `ArchitectureCheck.AssertValid(string? solutionPath)`.

- [ ] **Step 1: Add the package** — `<PackageVersion Include="Ariadne.NET.Testing" Version="<release from Task 1>" />` in `Directory.Packages.props`, and a version-less `PackageReference` in the unit test project.
- [ ] **Step 2: Write the test** — `Solution_follows_the_architecture_pack` finds `Daedalus.sln` by walking up from `AppContext.BaseDirectory` and calls `ArchitectureCheck.AssertValid` on it.
- [ ] **Step 3: Run it** — `dotnet test tests/Daedalus.Tests.Unit --filter FullyQualifiedName~AriadneArchitectureTests`. Expected: PASS. Record its time for the PR body.
- [ ] **Step 4: Prove a missing pack fails** — rename `.architecture/rules.yaml` aside, run the test, confirm it fails with an `ArchitectureCheckException` message about the missing pack, rename it back.
- [ ] **Step 5: Triage any failure from Step 3** — for each violation: when the catalogue's `Divergences` on `docs-site/docs/archunitnet-parity.md` lists the construct, adjust the pack and note it for the PR body; when the code really breaks the rule and ArchUnitNET missed it, stop and report to the owner; anything else, stop and report as a parity gap.
- [ ] **Step 6: Run the checks** — `dotnet build Daedalus.sln` with no warnings, and `dotnet test tests/Daedalus.Tests.Unit`, with the ArchUnitNET tests still passing.
- [ ] **Step 7: Commit** — `test: check the architecture with Ariadne.NET.Testing`.

### Task 3: Red checks

**Files (Daedalus.NET):** none committed.

- [ ] **Step 1: List the rule groups** — one line per layer `allowedDependencies`, `forbid` rule, `allowOnly` rule, `require` rule, `uniqueNames` rule and `bannedPackages` rule in the pack, with its id.
- [ ] **Step 2: For each group, mutate, run and revert** — apply the mutation the replaced ArchUnitNET fact's `Red:` comment describes, or the smallest equivalent: a field of a forbidden type, a class moved to the wrong project, a package reference added. Run `dotnet test tests/Daedalus.Tests.Unit --filter FullyQualifiedName~AriadneArchitectureTests`. Expected: FAIL, the message names the group's id. Revert with `git checkout -- .` and `git status --short` shows nothing outside the branch's commits.
- [ ] **Step 3: Fix a rule that stays green** — correct the pack, commit it as `fix: tighten the Ariadne pack rule <id>`, and repeat its red check. If the fix is not clear, stop and report.
- [ ] **Step 4: Write the table** — `| Rule id | Mutation | Ariadne result |` for the PR body, every row red.

### Task 4: Delete ArchUnitNET and open the PR

**Files (Daedalus.NET):**
- Delete: `tests/Daedalus.Tests.Unit/Architecture/CleanArchitectureTests.cs`, `tests/Daedalus.Tests.Unit/Architecture/NoEntityFrameworkTests.cs`
- Create, only when Step 1 finds a fact to keep: `tests/Daedalus.Tests.Unit/Architecture/RetainedArchitectureTests.cs`
- Modify: `Directory.Packages.props`, every project that references `TngTech.ArchUnitNET.xUnit`

- [ ] **Step 1: Keep the facts that stay in C#** — list every `[Fact]` in the two files that the guide's test map, or Task 1 Step 4, marks `stays in C#`. Move each to `RetainedArchitectureTests.cs`, rewritten without ArchUnitNET, for example as reflection over the loaded assemblies or a scan of the project files, with its `Because` text and `Red:` comment kept. Run `dotnet test tests/Daedalus.Tests.Unit --filter FullyQualifiedName~RetainedArchitectureTests` and apply each fact's `Red:` mutation once to see it fail, then revert. A fact that cannot be written without ArchUnitNET: stop and ask the owner before deleting anything. Commit as `test: keep the architecture facts Ariadne does not cover`.
- [ ] **Step 1a: Delete** — the two files, the package everywhere, and any helper or `using` only they needed. Before deleting, confirm that every `[Fact]` in them is either mapped to a pack rule or `not needed` in the test map, or now lives in `RetainedArchitectureTests.cs`.
- [ ] **Step 2: Check nothing is left** — `grep -ri archunit --exclude-dir=bin --exclude-dir=obj --exclude=CHANGELOG.md .`. Expected: no output.
- [ ] **Step 3: Run the checks** — `dotnet build Daedalus.sln` with no warnings, `dotnet test tests/Daedalus.Tests.Unit`. Expected: PASS.
- [ ] **Step 4: Commit** — `test: replace the ArchUnitNET tests with the Ariadne pack`. Not `test!`: no public API changes.
- [ ] **Step 5: Push and open the PR** — body: what changed, the Ariadne version, the red-check table, the test time, the divergence notes from Task 2, and that the `Directory.Packages.props` part of the package-absence facts is dropped on purpose. Wait for Daedalus CI to be green, integration tests included. The owner merges.

# Phase 3.1 — Ariadne.NET.Testing Implementation Plan

> Execution method: none now. This plan is built later, by an unattended run or by `start-next-phase`.

**Design:** `docs/superpowers/specs/2026-11-10-phase-3.1-ariadne-net-testing-design.md`
**Goal:** One call in a test checks every pack under `.architecture/` against the solution; the CLI, stop hook and MCP check the same packs, and each violation names its pack.
**Approved public API:** `ArchitectureViolation.Pack`, `TextReportWriter`, `IPackSetValidator` and its registration in `AddAriadneNETWorkspaces()`, and the new `Ariadne.NET.Testing` package with `ArchitectureCheck`, `ArchitectureCheckException` and `ArchitectureViolationException`. Approved by the owner with the milestone 3 design on 2026-11-10 and confirmed for the unattended run; none of it is a breaking change.
**Conventions:** conventional commits, no nested parentheses in bodies, no `Co-Authored-By` trailer or session link, footer lines under 100 characters. `TreatWarningsAsErrors` is on; one type per file; tests are xUnit + FluentAssertions. One build or test at a time.

**Files:** `src/Ariadne.NET.Testing/Ariadne.NET.Testing.csproj`, `src/Ariadne.NET.Testing/buildTransitive/Ariadne.NET.Testing.props`, `Ariadne.NET.slnx`, design spec (outcome section)

- [x] Pack it into a temp folder, create a throwaway console project outside the repo that references only the package from that feed (with a nuget.config pointing at the feed plus nuget.org), and build it with no `Microsoft.Build.Framework` reference. Record whether `MSBL001` appears.
- [x] If it does, add the `buildTransitive` props that add `<PackageReference Include="Microsoft.Build.Framework" Version="17.14.28" ExcludeAssets="runtime" />` to the consumer. Rebuild the throwaway project. Repeat until it builds without `MSBL001`, or until it is clear that MSBuild does not allow it.
- [x] Add a heading "Spike outcome" to the design spec with the result: either "shipped by the package's props" with the file, or "not possible" with the error and the line the consumer must add. Remove the throwaway project.
